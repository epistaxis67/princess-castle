# Princess Castle – Website

Kleine statische Website: Eine historische Postkarte (Petit Trianon) dreht sich beim Anklicken zum Briefumschlag, das Siegel bricht, der Brief gleitet heraus – danach erscheint der Briefbogen „Princess Castle“ als lesbare Seite.

## Dateien

```
index.html      Inhalt (Text des Briefbogens)
style.css       Gestaltung & Animation
script.js       Ablauf der Umschlag-Animation
postkarte.jpg   Postkarte (Vorderseite des Umschlags)
logo.png        Kalligrafischer Briefkopf (transparent, aus dem PDF)
```

Schriften: EB Garamond und Pinyon Script (Google Fonts, werden online geladen).

## Auf GitHub Pages veröffentlichen

1. Auf github.com ein neues Repository anlegen, z. B. `princess-castle`.
2. „uploading an existing file“ wählen und alle 6 Dateien dieses Ordners hochladen (einfach alle markieren und ins Fenster ziehen).
3. Im Repository: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save.
4. Nach ca. einer Minute ist die Seite erreichbar unter `https://<benutzername>.github.io/princess-castle/`.

Tipp: `…/#brief` öffnet direkt den Brief ohne Animation.

## Lokal ansehen

`index.html` im Browser öffnen (doppelklicken) – fertig.
